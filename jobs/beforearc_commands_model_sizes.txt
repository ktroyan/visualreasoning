*** All commands to run the model sizes experiments in Before-ARC ***

NOTE:
- We specify the relevant parameters based on the default configs.
- Need to change the network default config since the network arguments have not been added as possible arguments for the job.


### Experiment 1 of CompGen Settings at 10M samples for 10 epochs ###

## Grid-TF
# Bash
bash ./jobs/run_experiment_nohup.sh --sweep_enabled true --sweep_config "configs/sweeps/beforearc/comp_scaling_samples_exp1_1M_10epochs.yaml" --backbone vit --visual_tokens_enabled true --ape_enabled true --ape_type 2dsincos --ape_mixer weighted_sum_vec --ope_enabled true --rpe_enabled true --rpe_type rope --num_reg_tokens 6 --add_log_name "Grid-TF" --max_epochs 10 --gpu_id 1 --seed 1997 --wandb_project_name "VisReas-project-model-sizes"

# SLURM
sbatch jobs/run_experiment_wrapper.slurm --sweep_enabled true --sweep_config "configs/sweeps/beforearc/comp_scaling_samples_exp1_1M_10epochs.yaml" --backbone vit --visual_tokens_enabled true --ape_enabled true --ape_type 2dsincos --ape_mixer weighted_sum_vec --ope_enabled true --rpe_enabled true --rpe_type rope --num_reg_tokens 6 --add_log_name "Grid-TF" --max_epochs 10 --seed 1997 --wandb_project_name "VisReas-project-model-sizes"
